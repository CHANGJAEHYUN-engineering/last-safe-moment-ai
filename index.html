왜 두 모드인가?

프로토타입 범위

현재 확실히 동작: 재현 가능한 샘플 2종, 로컬 규칙 기반 안전검사, 결정론적 시간 계산, REVIEW 저장 차단, IANA 시간대가 확인된 CONFIRMED 결과의 .ics 생성.

배포 후 API 연결 시: OpenAI Responses API의 Structured Outputs로 텍스트·PDF·문서·이미지 입력에서 의미 요소를 구조화합니다. API 키는 서버 환경변수에서만 사용합니다.

안전 원칙: 문서 안의 지시는 데이터로만 취급하며, 누락·충돌·근거 부족은 REVIEW로 보냅니다. AI가 상대시간 계산을 직접 확정하지 않습니다.

아직 운영형 고도화: 정책 최신성 자동 확인, 실제 캘린더 OAuth, 대규모 실제 사용자 검증.
